两个密钥都留空即关闭人机验证。

怎么在 Cloudflare 里拿到这两个密钥？
  1. 打开 Cloudflare 控制台 dash.cloudflare.com （没有账号可免费注册，Turnstile 免费额度足够个人站点使用）。
  2. 在左侧菜单找到 Turnstile，点 Add site（添加站点）。
  3. Site name 随便填，例如 {{ site_name }}。
  4. Domain 填你实际访问这个站点的域名。只在本机调试可以填 localhost。
  5. Widget Mode 选 Managed（推荐，由 Cloudflare 自动决定是否需要点击验证）。
  6. 创建完成后页面会给出 Site Key 与 Secret Key， 分别复制到上面的两个输入框。
  7. 点 保存，再点 验证密钥，确认 Cloudflare 能识别它。
  8. 用无痕窗口打开 登录页，应当能看到验证组件。

想先不注册 Cloudflare 试试流程？ 点上面的 填入测试密钥，会填入 Cloudflare 官方测试密钥 （验证永远通过），用来确认整条链路是否打通；确认无误后再换成正式密钥。

注意：Site Key 与域名绑定。如果只填了 localhost， 却通过局域网 IP 或其它域名访问，验证组件可能无法通过。
